Migración SQLite → PostgreSQL

        

          

            Para migrar a PostgreSQL: instala PostgreSQL, crea la base de datos, ejecuta
            alembic upgrade head para crear las tablas, luego ejecuta el siguiente comando:
          

          
python db_tools.py migrate --from sqlite:///data/mrd_tool.db --to postgresql://user:pass@host/dbname

          

            Actualiza MRD_DATABASE_URL en config/local.env y reinicia el servicio.
            Para múltiples workers, ajusta también service.yaml.
