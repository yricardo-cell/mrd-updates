Instalación rápida

Ejecuta en PowerShell como Administrador desde la carpeta del proyecto:

# Instalar cloudflared como servicio con Named Tunnel
.\install_cloudflared.ps1 -TunnelName "mrd-tool" -Hostname "herramientas.midominio.com"

# Solo actualizar DNS (túnel ya creado)
.\install_cloudflared.ps1 -TunnelName "mrd-tool" -Hostname "herramientas.midominio.com" -ConfigOnly

# Desinstalar
.\install_cloudflared.ps1 -UninstallOnly

El script descarga cloudflared, hace login en Cloudflare, crea el túnel, configura DNS y lo instala como servicio Windows con inicio automático.
